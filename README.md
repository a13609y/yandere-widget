# yande.re 动漫图 · Egern 小组件

从 [yande.re](https://yande.re) / [Konachan](https://konachan.net) 按标签取动漫插画，按小组件尺寸匹配画幅；免登录，sample 图长边 1500px、体积小。

**v8.0 起改用「洗牌袋」换图**：一次要一页清单（不下载图片），本地洗牌后逐张发，一袋之内绝不重复，袋与袋之间几乎不重复。

## 安装

Egern → 模块 → 右上角 + → 从 URL 导入：

```
https://raw.githubusercontent.com/a13609y/yandere-widget/main/yandere.yaml
```

然后添加小组件（小号 / 中号 / 大号 / 超大号都支持，另有锁屏圆形与矩形）。

## 洗牌袋是怎么换图的

1. 补货时向源站要**一页清单**（100 条元数据，1 个请求，**不下载图片**）；
2. 本地洗牌后放进「袋子」，之后每次刷新**按顺序发一张**（每次仍只下 1 张图）；
3. 袋子发完（或小于 12 张）再补下一袋；补货时会剔掉最近看过的、并可能换一个自然月。

好处：一袋之内零重复、请求极少（默认配置实测 5 次刷新只花 2 个请求），也不会一次抓一堆被图床当爬虫。

**机会式预补货（v8.1）**：在「本来命中缓存、5 毫秒就返回」的那次渲染里，顺手把袋子补一点（显示的还是旧图，用户无感）。这样到点真正换图时只剩下载一张图 —— 实测从 2~10 秒降到 **1 秒左右**。

## 参数（18 个）

设置项顺序：**换图间隔 → 分级 → 内容 → 画幅 → 过滤 → 显示**。

| 分组 | 参数 | 默认 | 说明 |
|---|---|---|---|
| 换图间隔 | COOLDOWN | 30 | 分钟；填 **0** = 每次刷新都换（测试用） |
| 分级 | 全年龄 s / 擦边 q / 工口 e | 开 / 开 / 关 | 独立开关；全关按「仅全年龄」处理；勾 q/e 时自动走 `konachan.com` |
| 内容 | 标签 | 空 | 空格或逗号分隔，多个是「同时满足」；中文也行（初音 → hatsune_miku） |
| 内容 | 图源 | 自动 | Konachan 优先，返回 0 条才用 yande.re |
| 内容 | 排序 | 随机 | 随机 / 热度 / 最新 —— **选哪个会自动套一套洗牌参数**，见下表 |
| 内容 | 时段 | 三年内 | 一天内 … 三年内 / 六年内 / 不限；「最新」排序会忽略时段 |
| 画幅 | 自定义容忍 | 开 | 关 = 粗分档；开 = 按理想比例 ±容忍百分比 |
| 画幅 | 容忍百分比 | 10 | 横 1.60~1.96、方 1.20~1.46、竖 0.64~0.78 |
| 画幅 | 尺寸适配 | 自动 | 自动 = 小号方图 / 中号横图 / 大号方图 / 超大号横图；也可统一成方/横/竖/不限 |
| 过滤 | 最小短边 | 1024 | 低于这个值的 60% 直接跳过 |
| 过滤 | 露点 / 多格 / 白底透明底 | 关 / 开 / 开 | 白底项整词匹配 white、transparent、transparent_background |
| 过滤 | 自定义标签 | 空 | 逗号分隔（`guro, vore`），标签内空格自动转下划线 |
| 显示 | 分辨率 | 关 | 左下角显示分辨率 + ♥ 数，想看再开 |
| 显示 | 调试角标 | 关 | 一行状态：版本/图源/比例/画幅/分级/体积/排序/时段 |

**固定值（不再暴露成变量）**：防重复窗口 200 条；画师去重关；变体去重开。

### 排序对应的洗牌参数

| 排序 | 每袋张数 | 按月切块 | 允许重复 |
|---|---|---|---|
| 随机 | 50 | 开 | 0% |
| 热度 | 30 | 开 | 10% |
| 最新 | 20 | 关 | 0% |

- **按月切块**：补货时随机挑一个自然月（如 2024-03）只在这个月里取图，时间分布均匀、不会老看到最近那批；
- **允许重复**：有多大概率回放一张「最久没出现」的旧图（最近 8 次出现过的不会回放）；
- 素材太薄（一袋装不满 12 张，比如只勾工口）时，**下次自动不切月**，改用整个时段。

## 画幅判定

**粗分档（关掉自定义容忍时）**：≥1.35 横 / 0.75~1.35 方 / <0.75 竖。

**自定义容忍（默认开，10%）**：按 booru 的真实比例收图 —— 横 1.78、**方 1.33（4:3，不是 1:1）**、竖 0.71，上下浮动 10%。方图这一项特别说明：booru 的“方图”实测 84% 都是 4:3，以前按 1.00 算几乎一张都取不到。

## 时段与素材量（实测，Konachan）

| 时段 | 说明 |
|---|---|
| 一天内 / 一周内 | 素材少，图的分普遍 40~60 |
| 一年内 | 全年龄最高约 190 分 |
| 三年内（默认） | 素材充足，是默认档 |
| 六年内 / 不限 | 更多，但会更早的图；「不限」可能翻到十几年前的 |

## 已知限制

- **yande.re 的 `order:random` 叠加 `date:` 只回 0~3 条**（站点毛病）→ 代码里会自动换成 `order:date` + 随机页；
- **图床偶尔 307 回图片页**（限流）→ 会原样重试一次，仍失败就换一张，错误的图不再反复试；
- **热度是固定排行榜**：同一月内越翻越差，10 页后回卷；
- **单张 >1.2MB 跳过**（iOS 桌面画不出来）。

## 反馈

调试角标打开后，调试行会显示版本号（当前 `v8.0`）、图源、画幅、搜索次数等。遇到问题把这行发出来即可定位。
