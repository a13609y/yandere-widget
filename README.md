# Wallhaven 动漫壁纸 · Egern 小组件

从 [Wallhaven](https://wallhaven.cc) 取动漫壁纸，按小组件尺寸自动匹配画幅。免登录可用，R18 需要免费的 API Key。

## 安装

Egern → 模块 → 右上角 + → 从 URL 导入：

```
https://raw.githubusercontent.com/a13609y/wallhaven-widget/main/wallhaven.yaml
```

导入后到「模块 → Wallhaven 动漫壁纸」里设置参数，然后添加小组件。

> 修改参数后如果没生效：删掉模块重新导入一次（Egern 对脚本有 `update_interval` 缓存）。

## 参数

| 参数 | 作用 | 默认 |
|---|---|---|
| 关键词 | 留空 = 随机；填了按关键词搜（`girl`、`blue_sky`、`!exact`、`-排除`） | 空 |
| 排序 | **只在有关键词时生效**：相关度 / 最新 / 热度 / 随机 | 相关度 |
| 画幅·小号 / 中号 / 大号 / 超大号 | 每个尺寸单独设：方图 / 横图 / 竖图 / 不限 | 方/横/方/横 |
| 内容分级 | 仅 SFW / SFW+Sketchy / 全部（含 R18，需 Key） | 仅 SFW |
| API Key | Wallhaven 账号里的 Key，只在开 R18 时用到 | 空 |
| 分类 | 动漫 / 全部 | 动漫 |
| 最低分辨率 | 不限 / 1280x720 / 1920x1080 / 2560x1440 | 1920x1080 |
| 单张大小上限 | 1 / 2 / 4 / 8 / 不限 MB | 2 |
| 图片质量 | 省流（卡大小上限）/ 高清（不限制） | 省流 |
| 换图间隔 | 分钟，0 = 每次刷新都换 | 30 |
| 防重复窗口 | 显示过的作品在这 N 张内不再出现 | 100 |
| 显示分辨率 | 右下角显示分辨率 + 热度 | true |
| 调试角标 | 显示版本/比例/分级/大小/关键词/搜索次数 | false |

### 画幅是怎么翻译的

| 选项 | 实际请求 |
|---|---|
| 方图 | `ratios=1x1,5x4,4x5`（严格 1:1 为主，带近方形） |
| 横图 | `ratios=landscape` |
| 竖图 | `ratios=portrait` |
| 不限 | 不传 ratios |

Wallhaven **没有** `square` 这个取值，写了会被静默忽略（返回横图），所以这里用 `1x1`。

## R18 怎么开

1. 注册并登录 [wallhaven.cc](https://wallhaven.cc)；
2. 打开 **Account settings** → 找到 **API Key** 一栏（免费的，注册即有）；
3. 页面底部把 **NSFW** 相关开关打开（账号本身要允许显示 NSFW，否则接口仍只返回 SFW）；
4. 把 Key 填进模块的「Wallhaven API Key」，内容分级选「全部（含 R18，需 API Key）」。

**没填 Key 却选了「全部」会自动降级成 SFW + Sketchy**，不会报错，调试角标会显示 `⚠无 Key 降级`。

## 常见问题

**一张图都没有 / 提示“没有符合条件的结果”**
关键词 + 画幅 + 分级三重过滤可能真的没有交集。比如 `blue_sky` 在「方图」下全站是 0 张。换个词，或把该尺寸的画幅改成「不限」。

**图片模糊**
「最低分辨率」调到 1920x1080 以上；「图片质量」选「高清」。

**内存/闪退**
「单张大小上限」调到 1 或 2 MB，别用「高清」。小组件的图片是整张塞进缓存的，几 MB 的原图会吃内存。

**换图不积极**
`换图间隔` 只是建议值，iOS 有自己的刷新预算（每个小组件每天几十次），设成 0 也不会真的每分钟换。

**R18 还是不出**
Wallhaven 对 NSFW 是双重限制：账号设置里要允许 NSFW，接口还要带 `apikey`。两者缺一都只返回 SFW/Sketchy。
